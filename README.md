
# TP2 - Estadísticas Deportivas

Proyecto desarrollado para la materia Organización Empresarial - UTN TUP.

## Objetivo

Desarrollar un sistema de análisis de estadísticas deportivas utilizando Python, aplicando trabajo colaborativo mediante Git, GitHub y Google Colab.

El programa permite:
- Leer datos deportivos desde archivos CSV
- Calcular estadísticas de equipos
- Generar tablas de posiciones
- Crear gráficos comparativos
- Simular un entorno de desarrollo colaborativo

## Escenario elegido

Se seleccionó un escenario de análisis de resultados deportivos de fútbol, donde el sistema procesa información de distintos partidos y genera estadísticas automáticas de rendimiento de los equipos.

## Dataset utilizado

El proyecto utiliza un archivo CSV con resultados de partidos de fútbol.

Columnas principales:
- equipo_local
- goles_local
- equipo_visitante
- goles_visitante

El dataset se encuentra dentro de la carpeta:

datos/

## Instrucciones de ejecución

1. Clonar el repositorio en Google Colab.
2. Configurar credenciales de Git.
3. Ejecutar los scripts ubicados en la carpeta scripts/.
4. Verificar los resultados generados en la carpeta resultados/.
